# Cheat Sheet info tech



to create a repo:use (git init) in the directory you want to be a repo

to send a file to staging area: use command (git add (file name))

to commit use the command: git commit -m "(descriptive message)"

to clone a repo, go to GitHub, click on profile, click on repositories, click on code, copy the HTML link 

and go to terminal and in desired directory type command:(git clone (HTTPS address))

use (git push origin main) to push the work to GitHub and (git pull origin main) to pull an already cloned repo.
